# 全息试衣间 POC（路线 A：纯 Web，三场景全流程）

> 2026-07-15 ｜ 对应《AI换装方案.md》门店大屏全流程：选衣 → 换装照片 → 户外视频

| 场景 | 页面 | 内容 |
|---|---|---|
| ① 选衣 | `index.html` | 全息光柱（常态缓慢自转 + 拖拽旋转，无播放器控件）+ 两侧衣架 + 玻璃面板 + 底部试穿间操作条（收藏此款 → 试穿间托盘 → 生成换装照片） |
| ② 换装照片效果 | `scene2.html` | 仅对试穿间收藏款生成照片（固定 4 角度切换，2D 不做 3D）+ 尺寸匹配/评分/雷达对比 |
| ③ 户外动态视频 | `scene3.html` | 场景②选定的单款换装视频在户外场景循环呈现（庭园夜径/高尔夫黄昏/石拱庭院/庄园门前/暮色门廊五场景，无播放器语义）+ 扫码保存 |

**业务漏斗（递减）**：浏览 6 款 → 收藏 n 款进试穿间 → n 款逐一看照片效果 → 选定 1 款生成户外视频。跨页通过 `?fav=`（收藏的全局索引）与 `?g=`（选定款）传递，返回时状态不丢。场景①收藏为空时「生成换装照片」置灰。各场景有返回按钮，右下角有步骤指示。

## 怎么打开

- 双击 `start.command`（本地起服务并打开浏览器），或
- 任何静态服务器指向本目录后访问 `index.html`

门店部署时用 Chrome kiosk 模式全屏：

```
chrome --kiosk --autoplay-policy=no-user-gesture-required http://localhost:8765/index.html
```

## 技术要点

- **单文件纯 Web**：HTML/CSS + Canvas 粒子，零外部依赖、零 License，离线可用
- **固定 1920×1080 舞台整体缩放**：任何分辨率大屏布局不变形（kiosk 常用做法）
- **中央全息光柱**：CSS 渐变光柱 + 扫描线动画 + Canvas 上升粒子 + 倒影，人物为透明底序列帧，**拖拽即 360° 旋转**（`assets/seq/`，60 帧，来自换装 360° 视频抽帧 + rembg 抠图）
- **两侧悬浮衣服**：挂拍图 rembg 抠图 + 发光描边 + 浮动动画
- **玻璃拟态面板**：`backdrop-filter: blur`，尺码/材质/颜色/商品信息/合身度/AI 建议

## URL 参数（演示用）

- `?still` — 跳过入场动画（截图/录屏用，三个页面均支持）
- `?fav=0,2,4` — 试穿间收藏款（全局索引，场景①②③贯通传递）
- `?sel=n` — 场景① 默认选中第 n 件（全局索引）；场景② 为收藏列表内第 n 款
- `?g=n` — 场景②③ 指定选定款（全局索引，场景③返回场景②时使用）
- `?view=front|back|left|right` — 场景② 默认视角
- `?scene=0..4` — 场景③ 默认户外场景（0 庭园夜径 / 1 高尔夫黄昏 / 2 石拱庭院 / 3 庄园门前 / 4 暮色门廊）

## 素材目录

- `assets/garments/` — 挂拍衣服抠图（g1 真实白 Polo，g2-g6 为调色占位）
- `assets/seq/` — 顾客 360° 转身序列帧 60 帧（rembg 抠图）
- `assets/customer/` — 顾客固定 4 角度照片抠图：a=左侧 b=正面 c=右侧 d=背面
- `assets/outdoor/` — 场景背景 5 张在用（Unsplash：garden=酒店庭园夜径、golf=高尔夫黄金时刻、courtyard=石拱庭院夜景、manor=乡村庄园门前夜景；Wikimedia：veranda=暮色酒店门廊。选图标准：平视视角 + 竖线不倾斜 + 中央可站立地面 + 暖调光线 + 高端场所调性。piazza.jpg 已弃用但保留在目录。商用请替换有授权图库）

## POC 占位内容（正式版要替换）

| 占位 | 正式版 |
|---|---|
| 衣架上的 5 个配色是 g1 调色生成的假配色 | 每个 SKU 的真实挂拍图（BiRefNet/rembg 抠图，全自动） |
| 商品名/价格/合身度/尺寸匹配/评分/AI 建议全是写死的假数据 | 接门店商品库 + 后端接口（WebSocket/HTTP） |
| 场景② 中央照片 = 顾客原照（本就穿藏青 Polo，正好当"换装成藏青款"的结果） | Qwen-Image-Edit 换装输出的 4 角度照片，按所选款式切换 |
| 场景③ 的"视频" = 360° 序列帧循环播放 + 静态背景合成（落地感靠接触阴影 + 湿地面倒影 + 人物色调匹配三件套模拟） | Wan 2.2 I2V 生成的真实 mp4（人和场景一体生成，无需合成技巧），`<video>` 标签直接播 |
| 场景③ 二维码是 canvas 画的假码 | 接视频下载短链生成真实二维码 |
| 场景① CTA 假进度 | 触发 ComfyUI 换装流水线（见 AI换装方案.md） |

## 素材流水线（本 POC 的生成方式，可脚本化）

```
挂拍图/序列帧 → rembg (u2net) 抠透明底 → 缩放 → webp
```

单件衣服处理约 1–2 秒，可全自动，上新当天完成。
